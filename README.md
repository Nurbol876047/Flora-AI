# Flora AI — интеллектуальный определитель растений родного края

Школьный исследовательский инструмент для полевого определения растений
Кызылординской области и Приаралья. Загружается фотография растения,
определение выполняется в два шага: ботаническая база **Pl@ntNet** даёт
визуальную гипотезу, языковая модель (**OpenAI**) формирует итоговую
карточку гербария на русском и казахском языках.

## Возможности

- **Определение** — фото → Pl@ntNet (топ-3 вида) → LLM (карточка: названия,
  семейство, описание, место обитания, встречаемость в регионе, ядовитость,
  охранный статус, похожие виды). Если уверенность ниже 50% — предупреждение
  о необходимости повторной съёмки. Если определённый вид входит в Красную
  книгу РК — строгая плашка-предупреждение о запрете сбора.
- **Определитель по признакам** — пошаговый мастер (жизненная форма →
  местообитание → окраска цветка → тип листа) по каталогу `plants.json`.
  Работает полностью офлайн, без обращения к API.
- **Карта** — Leaflet/OpenStreetMap, точки журнала наблюдений с известными
  координатами (из EXIF фото, геолокации устройства или введённых вручную).
- **Журнал наблюдений** — каждое определение сохраняется в браузере
  (`localStorage`) с номером образца `FA-0001…`, датой, местом, координатами
  и фото; таблица с сортировкой, фильтром и экспортом в CSV.
- **Флора края** — каталог из 15 характерных видов региона (саксаул,
  тамариск, джузгун, верблюжья колючка, тюльпан Шренка, туранга, адыраспан
  и др.) с поиском по названию, фильтрами по семейству/местообитанию и
  карточкой-модалкой с полным описанием.
- **Красная книга** — охраняемые виды из каталога «Флора края» и справочный
  список латинских названий (`data/redbook.json`) для сверки результатов
  определения.
- **О проекте** — цель, методика, ограничения метода и честная оговорка
  о возможных ошибках ИИ.
- Переключение интерфейса RU / ҚАЗ.

## Технологии

Next.js 14 (App Router) + React. Стиль «лабораторный минимализм» реализован
на чистом CSS (`src/app/globals.css`), шрифты — IBM Plex Sans и IBM Plex Mono
(через `next/font/google`). Из внешних библиотек: **Leaflet** (карта) и
**exifr** (чтение GPS из EXIF фотографии, выполняется в браузере).

## Установка и запуск

```bash
npm install
cp .env.example .env.local
```

Откройте `.env.local` и заполните ключи (см. ниже), затем:

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:3000`.

## Как получить ключи API

### OpenAI (обязателен)

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com/).
2. Перейдите в **Settings → API keys** и создайте новый ключ.
3. Пополните баланс (используется оплата по факту запросов; для школьного
   проекта расходы минимальны при модели `gpt-4o-mini`).
4. Вставьте ключ в `.env.local`:
   ```
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=gpt-4o-mini
   ```

**Важно:** ключ используется только в серверном коде
(`src/app/api/identify/route.js`, `src/lib/llm.js`) и никогда не передаётся
в браузер. Не публикуйте `.env.local` и не вставляйте ключи в чаты/код —
если ключ попал куда-то наружу (например, в переписку), отозвите его в
панели OpenAI (**Settings → API keys → Revoke**) и создайте новый.

### Pl@ntNet (опционально, но рекомендуется)

1. Зарегистрируйтесь на [my.plantnet.org](https://my.plantnet.org/).
2. В личном кабинете найдите раздел **"Get an API key"** — для учебного и
   некоммерческого использования ключ выдаётся бесплатно (с лимитом запросов
   в сутки).
3. Вставьте ключ в `.env.local`:
   ```
   PLANTNET_API_KEY=ваш_ключ
   ```

Если ключ Pl@ntNet не указан (или сервис не отвечает), приложение
автоматически переходит в **запасной режим**: определение выполняется
только языковой моделью по фотографии, результат помечается как
«предварительно».

## О данных в plants.json и redbook.json

Эти файлы составлены вручную по открытым ботаническим источникам (включая
Wikimedia Commons для фотографий). **Латинские названия, статус Красной
книги и фотографии нужно сверить вручную** с актуальными ботаническими
определителями и официальным изданием Красной книги Республики Казахстан
перед использованием результатов в отчётах, публикациях или на конкурсах.
Два изображения (джузгун, солянка) — представители рода, а не точного вида
(в Wikimedia Commons не нашлось фото именно этих видов) — см. поле
`imageNote` в `plants.json`.

## Ограничения

- Журнал наблюдений хранится локально в браузере пользователя
  (`localStorage`), а не на сервере — это достаточно для одного устройства
  и учебной демонстрации, но записи не синхронизируются между устройствами.
- Определение по фотографии не заменяет гербарную экспертизу. Подробнее —
  на странице «О проекте» в самом приложении.
- Карта использует координаты только из тех записей журнала, где они известны
  (EXIF фото, геолокация устройства или распознанный из текста формат
  «широта, долгота»); записи без координат на карте не отображаются.
